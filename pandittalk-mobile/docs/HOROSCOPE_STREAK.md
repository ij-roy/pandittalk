# Daily horoscope streak

Issue #262: the free daily horoscope had no reason to come back tomorrow.

Opening a daily result records one day on this device. The same calendar day does not add another day. A visit the next day continues the streak. A longer gap starts again at 1. The sign picker shows the current streak, or a prompt to start one.

The monthly horoscope does not change the streak.
