# Confirmation join instructions

After a booking is confirmed, the confirmation screen lists how to join.

The steps say to open the session from My Bookings a few minutes early, which permission to allow for audio or video, and that coins return to the wallet if the pandit has not joined within 10 minutes. Chat tells the user to stay in the chat until the pandit replies. The screen scrolls so the steps stay reachable on a short phone.
